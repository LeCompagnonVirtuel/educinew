## 2. Signaler un problème

### Via l'application

1. Menu → Aide → Signaler un problème
2. Sélectionner la catégorie
3. Décrire le problème
4. Joindre des captures d'écran
5. Soumettre

### Via email

Envoyer à support@educi.com avec :
- Sujet: [Module] Description courte
- Description détaillée
- Étapes de reproduction
- Capture d'écran
- Navigateur/appareil

## 4. FAQ

### Authentification

**Q: J'ai oublié mon mot de passe**
R: Utilisez "Mot de passe oublié" sur la page de connexion. Un email vous sera envoyé.

**Q: Mon compte est bloqué**
R: Après 5 tentatives échouées, le compte est bloqué 30 minutes. Contactez l'admin si besoin.

**Q: Je ne reçois pas le code MFA**
R: Vérifiez vos spams. Utilisez un autre méthode si disponible.

### Wallet

**Q: Comment ajouter de l'argent ?**
R: Via le menu Wallet → Recharger, ou demandez à l'administration.

**Q: Ma transaction a échoué**
R: Vérifiez votre solde. Si le problème persiste, contactez le support.

**Q: Comment demander un remboursement ?**
R: Contactez l'administration de votre école.

### Marketplace

**Q: Comment devenir vendeur ?**
R: Soumettez une demande via Admin → Marketplace → Vendeurs.

**Q: Ma commande n'arrive pas**
R: Vérifiez le statut dans Mes Commandes. Contactez le vendeur ou le support.

**Q: Comment retourner un produit ?**
R: Dans les 14 jours, via Mes Commandes → Retourner.

### Technical

**Q: L'application est lente**
R: Vérifiez votre connexion. Videz le cache du navigateur.

**Q: Les notifications ne marchent pas**
R: Vérifiez les permissions de notification dans votre navigateur/appareil.
