# EduOS Phase 3.4 — Guide Utilisateur

> Version : 3.4.0

---

## 1. Démarrage rapide

### Connexion

1. Ouvrir l'application EduOS (web ou mobile)
2. Entrer votre email et mot de passe
3. Compléter la vérification MFA si activée
4. Accéder à votre dashboard

### Dashboard

Le dashboard s'affiche selon votre rôle :

| Rôle | Widgets principaux |
|------|-------------------|
| Admin | Utilisateurs, Paiements, Alertes |
| Enseignant | Classes, Notes, Emploi du temps |
| Élève | Cours, Notes, Wallet |
| Parent | Enfants, Paiements, Messages |

---

## 2. Fonctionnalités par module

### Wallet Éducatif

#### Consulter le solde

1. Menu → Wallet
2. Le solde s'affiche en haut
3. Historique des transactions en dessous

#### Effectuer un paiement

1. Menu → Wallet → Payer
2. Scanner le QR code ou entrer la référence
3. Confirmer le montant
4. Valider avec biométrie ou PIN

#### Transférer

1. Menu → Wallet → Transférer
2. Sélectionner le destinataire
3. Entrer le montant
4. Confirmer

### Marketplace

#### Rechercher un produit

1. Menu → Marketplace
2. Utiliser la barre de recherche ou les filtres
3. Sélectionner un produit

#### Commander

1. Ajouter au panier
2. Vérifier le panier
3. Choisir le mode de livraison
4. Payer
5. Suivre la commande

### Présence (QR Code)

#### Pour les élèves

1. Scanner le QR code affiché par l'enseignant
2. La présence est enregistrée automatiquement
3. Notification de confirmation

#### Pour les enseignants

1. Générer le QR code depuis l'app
2. Afficher aux élèves
3. Consulter la liste de présence

### Communication

#### Envoyer un message

1. Menu → Messages
2. Nouveau message
3. Sélectionner le destinataire
4. Écrire et envoyer

#### Notifications

- Les notifications push arrivent automatiquement
- Consulter l'historique dans l'onglet Notifications
- Paramétrer les préférences dans Settings

## 3. Paramètres du compte

### Profil

1. Menu → Profile → Modifier
2. Changer photo, nom, email
3. Sauvegarder

### Sécurité

1. Menu → Profile → Sécurité
2. Activer/désactiver MFA
3. Ajouter méthode biométrique
4. Changer mot de passe
5. Gérer les sessions actives

### Préférences

1. Menu → Settings
2. Langue (FR, EN, AR, ES)
3. Notifications (on/off par type)
4. Thème (clair/sombre)
5. Fuseau horaire

## 4. FAQ

### Comment réinitialiser mon mot de passe ?

1. Page de connexion → "Mot de passe oublié"
2. Entrer votre email
3. Suivre le lien dans l'email
4. Choisir un nouveau mot de passe

### Mon wallet est bloqué, que faire ?

Contactez l'administration de votre école pour débloquer votre portefeuille.

### Je ne reçois pas les notifications

1. Vérifier les paramètres de notification
2. Vérifier les permissions de l'application
3. Vérifier la connexion réseau

### Comment vérifier une credential ?

1. Menu → Wallet → Credential
2. Scanner le QR code de la credential
3. La vérification s'affiche
